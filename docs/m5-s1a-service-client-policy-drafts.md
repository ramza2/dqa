# M5-S1A — 관리자 외부 서비스 정책 초안 등록 (개발 단계)

> 이 기능은 **관리자 전용 정책 초안 저장소**입니다. 컨소시엄에서 검토 중인
> `군의료AI_시스템_역할분리_구성도_초안_v1.1` 및
> `DEMIS_MCP_인터페이스_정의서_초안_v1.3`의 승인이나
> 실제 G2/보안/DBA/FHIR 계약 확정을 의미하지 않습니다.

## 구현 범위

- `/api/v1/admin/service-clients` 관리자 API
  - `GET /`: 초안 목록(페이지 한도 200)
  - `POST /`: 새 `DRAFT` 등록
  - `GET /{id}`: 상세 조회
  - `PATCH /{id}`: `DRAFT`의 비밀이 아닌 메타데이터·요청 범위 수정
  - `POST /{id}/revoke`: `REVOKED`로 영구 폐기
  - `GET /{id}/events`: append-only 변경 감사(액션·행위자·변경 필드명·정규화된 정책 SHA-256)
- 관리 필드: client ID, 서비스명, 기관·담당, 목적, 환경, **요청** scope와 **제안** IP/CIDR.
- CIDR은 IPv4/IPv6 정규화·중복 검사. 전체 공개 범위(`0.0.0.0/0`, `::/0`)는 차단.
- DB 저장 시 원문 비밀번호·서비스키·인증서·토큰 필드 없음. 미허용 입력은 422로 거부하며 비밀값을 응답에 재표시하지 않음.
- `CONNECTION_PROFILE_MANAGE` 관리자 권한 필요. 운영에서는 기존 승인된 IdP 부재 시 503 차단.
- 모든 변동과 감사 이벤트가 같은 PostgreSQL 트랜잭션에 기록됨. 상태가 `REVOKED`가 되면 수정·재활성화 불가.

## 이 단계가 구현하지 **않는** 것

1. `DRAFT`는 `ACTIVE`로 바뀔 수 없고, 등록된 scope/CIDR은 인증·인가에 적용되지 않습니다.
2. 클라이언트 자격증명·서비스키 발급, 검증, 회전, 재발급, mTLS/OAuth, IP 기반 인증이 없습니다.
3. REST/MCP 입구 또는 네트워크 포트를 외부로 열지 않습니다. 기존 **LLM-free / SELECT-only** 경로는 그대로입니다.
4. 관리자 환경 설정 UI 편집 기능은 아직 없습니다. 후속 M5-S1B에서 초안 UI와 추가 정책 검토를 진행합니다.
5. 실제 FHIR/SNUH.AI/DEMIS 실서비스 통신은 실시하지 않습니다.

## 운영·테스트 전제

Alembic 리비전 `20261030_m5s1a`을 적용해야 서버가 기동됩니다.
**기존 개발/운영 DB에서 `pytest`를 직접 실행하지 마세요.**
공통 `tests/conftest.py`의 DB fixture가 기존 테이블을 TRUNCATE합니다.

독립 검증은 `bash scripts/m5s1a-test-isolated.sh`로 실행합니다.
이 스크립트는 5432 포트가 이미 사용 중이면 **기존 DB 보호를 위해 중단**하고,
사용 가능한 경우에만 로컬 Docker의 tmpfs PostgreSQL을 생성해 Alembic과
관련 API 통합 테스트를 실행한 뒤 **자신이 만든 컨테이너만 제거**합니다.
기존 DB에 마이그레이션을 적용하지 않습니다.

외부 서비스 인증 자체는 후속 M5-S2의 별도 검토·승인 과제이며,
컨소시엄 회신이 오기 전에는 호출 계약과 실제 자격증명 정책을 확정하지 않습니다.
