# M5-L1D — 개발 전용 연결 후보 서버 정책 점검 UI (2026-11-02)

> M5-L1A 로컬 초안(#167), M5-L1B 정책 검증기(#168),
> M5-L1C 개발 전용 서버 검토 API(#169)의 프론트엔드 연결 단계.
> **설정 저장·연결 성공·LLM 사용 승인·기관 데이터 반출 승인 기능이 아니다.**

## 사용자 동작

1. 관리자 환경 설정 화면에서 **연결 후보 초안 열기**를 누른다.
2. **초안 입력 점검**은 기존과 같이 브라우저 내부에서만 실행하며 어떠한 API도 호출하지 않는다.
3. 서버의 관리자 상태 조회에 `llm.candidate_review_available=true`가 포함된
   **개발/테스트 환경**에서만 별도 **서버 정책 점검** 버튼이 표시된다.
4. 해당 버튼을 명시적으로 누른 경우에만 비밀정보 없는 후보의
   이름/배치환경/호출규격/URL/모델 ID/정수 타임아웃을
   `POST /api/v1/admin/integration-settings/llm-candidate/review`에 전송한다.
5. 서버가 돌려준 안전 판정 코드만 한국어로 표시한다. 원래 서버 주소,
   응답 예외/세부 오류/자격증명/허용 URL은 별도 출력하지 않는다.

서버에서 허용 URL이 일치하여 `POLICY_REVIEW_REQUIRED`를 반환하더라도
**운영 승인, 실제 연결 성공, 연결 시험 자격, 런타임 활성화**는 모두 부정한다.
HTTP URL/미지원 어댑터/허용 목록 미등록 URL은 서버 정책상 제한을 안내한다.

## 기본 차단 및 보안 경계

- 서버 기능은 기본 OFF. `APP_ENV=development|test`와 관리자 권한,
  `DQA_DEV_LLM_CANDIDATE_REVIEW_ENABLED=true`,
  `DQA_DEV_LLM_CANDIDATE_REVIEW_ALLOWED_BASE_URL`의
  정확한 승인 HTTPS 주소가 모두 있어야 서버에서 검토한다.
- 서버 주소 입력은 **후보 메타데이터**일 뿐, 해당 URL로 실제 DNS/HTTP
  요청을 보내지 않는다. ModelOps·SNUH.AI·실제 의료정보에 접속하지 않는다.
- 초기 화면/폼 열기/로컬 점검/입력 변경/초안 취소는 서버 POST가 아니다.
  입력이 바뀌거나 폼을 닫으면 오래된 비동기 검토 응답은 무시한다.
- 에러 세부 문자열은 UI에 표시하지 않는다. 개발 인증
  `dev_headers`를 운영 IdP로 오인하지 않는다.
- 실제 연결 정보 편집·비밀키 입력·저장·초기화·실행은 미지원 상태로 유지한다.
- CPU-first/LLM-free Query Template 검색·Preview·Oracle Mock SELECT 및
  감사와 무관하며, 외부 LLM으로 원문·임상자료·SQL 결과를 전송하지 않는다.

## 검증 범위

- 기존 관리자 상태/로컬 초안 테스트 회귀
- capability=false 시 서버 버튼 미노출, local-only 점검에서 POST 없음
- 사용자 명시 동작에서만 정확한 필드·정수 `timeoutSeconds` 전송
- 서버 정책 코드 표시, 승인 오인 방지, 예외 세부정보 마스킹
- 편집 중 비동기 응답 무효화, 컴포넌트 닫기 시 이전 초안 폐기
- 프론트엔드 빌드/린트, CI. 실제 서버 배포·연결 테스트는 이 PR 범위 밖

설정 편집·활성화는 운영 IdP, 기관 승인, 시크릿 관리, SSRF·DNS·리다이렉트
방어, 감사 및 변경 승인 절차가 마련된 별도 단계에서만 수행한다.
