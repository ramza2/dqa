# M5-L1A — 공급자 독립형 LLM 연결 후보 로컬 초안 UI

2026-11-02. M5-L0 모델 목록 연결성 성공 이후 단계. 실 운영 설정 변경이나 기관/LLM 사용 승인이 아니다.

## UI 계약

- 관리자 설정 조회 성공 후에만 초안 폼을 열 수 있다. 권한 실패 시 미노출.
- 연결 환경: ModelOps / SNUH.AI 등 기관 API / 자체 배포 모델(Hugging Face 포함) / 기타.
- API 호출 방식: OpenAI 호환 / 기타(전용 어댑터 예정). 모델 출처와 API 서버 종류는 독립적으로 표현한다.
- 필드: 연결 이름, API 서버 URL, 서버가 제공하는 모델 ID, 요청 타임아웃(1~300초).
- URL은 브라우저에서 HTTP(S), 자격증명 없는 주소인지 형식만 확인한다. HTTP는 경고한다.
- 키/토큰 입력·기존 URL/secret ref 조회 없음. 상태조회·연결 시험 API 계약은 변경 없음.
- 초안은 메모리에서만 유지되며 닫기/새로고침 시 제거된다. 실제 네트워크 호출/서버 저장/DB 기록 없음.
- 초안 초기화는 사용자 2단계 확인 후 입력값만 비우고 서버 설정은 건드리지 않는다.
- 실제 서버 설정 저장 및 연결 초기화 버튼은 비활성화한다.

Hugging Face 모델 다운로드만으로 호출할 수는 없다. 자체 설치 모델은 vLLM 등의
API 서버를 갖춰야 한다. SNUH.AI 별도 API 규격은 추후 공급자 어댑터로 연결한다.

## M5-L1 실제 설정 수정·초기화 선결 조건

1. 실 운영 관리자 IdP와 세션. dev_headers는 운영 관리자 증명이 아니다.
2. 승인된 비밀 저장소/인증정보 교체·회전/비밀값 무노출.
3. 허용 endpoint 정책과 SSRF/DNS rebinding/리다이렉션/프록시 통제.
4. 저장 이력/변경 전후 감사, 동시성 및 롤백/기본 비활성화.
5. 사용자 입력·환자정보·SQL row LLM 전송은 별도 승인 전 금지.
6. LLM 없이 템플릿 검색·검증·실행·감사 유지.

## 검증

Provider 선택지, URL 형식 거부, API 키 무노출, HTTP 경고, 미저장,
초안 초기화 2단계 및 닫기 시 소거, 미인가 시 폼 미노출를 FE 테스트한다.
